# IFE307: Embedded System (Teori)

**Kode MK:** IFE307 | **Kelas:** A | **SKS:** 2 SKS Teori  
**Dosen:** Dr. Ir. Wibowo Harry Sugiharto, M.Kom.  
**Semester:** Ganjil 2026/2027

---

## Deskripsi

Mata kuliah ini memberikan landasan teoritis sistem komputasi tertanam (*embedded system*): arsitektur mikrokontroler, antarmuka I/O, sensor dan aktuator, konsumsi daya, serta batasan waktu nyata berbasis platform Arduino.
